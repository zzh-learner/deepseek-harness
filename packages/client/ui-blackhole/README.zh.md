# @deepseek-ai/dsh-client-ui-blackhole

[English](README.md) | 中文

Web GARGANTUA 黑洞壁纸：零依赖 WebGL2 黑洞光线追踪，作为半透明背景层渲染，自带完整控制面板。场景（零测地线积分的引力透镜、带多普勒束流的薄吸积盘、程序化星空）逐字移植自独立版 GARGANTUA 项目；合成通道按亮度输出预乘 alpha——空域近乎透明，吸积盘与恒星保持实心。右侧可折叠面板保留项目全部参数（预设、吸积盘/时空/星空/渲染滑杆、FPS 统计、截图、交互轨道模式）并持久化到 localStorage。注册进 `shell.overlay`（沉在所有其他条目之下）与 `wallpaper.registry`（ui-wallpaper），未被选中时暂停渲染循环；不支持 WebGL2 的浏览器不渲染任何内容，并在面板中说明原因。

## 组合

```yaml
- id: ui-blackhole
  name: '@deepseek-ai/dsh-client-ui-blackhole'
```

仅浏览器半：一个 `shell.overlay` 列表条目（`order: -2000`，位于所有其他条目之下），加上 `wallpaper.registry` 中的 `gargantua` 注册项。节点半是惰性加载席位。画质默认「中」，低于 26fps 自动降档直到用户锁定档位；`prefers-reduced-motion` 禁用自动轨道并单帧渲染。

## 模型体验

无，因为壁纸是 WebGL2 画布上的浏览器侧环境渲染；这里没有任何内容进入模型请求。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **引擎是逐字移植，不是共享 WebGL 层** —— 光线追踪器持有自己的程序与渲染目标；第二个 WebGL 背景会复制整条管线而不是共享它。
- **截图合成的是原始画布** —— 截图下载引擎帧，不含面板；CSS 不透明度施加在画布元素上，并使用浏览器默认下载流程（没有应用内画廊）。
- **交互模式让画布接管指针事件** —— 拖拽轨道与滚轮缩放需要勾选开关，因为壁纸层位于所有可交互条目之下；常开手势会吞掉界面自身的指针输入。
- **整层 aria-hidden** —— 壁纸与其面板属于氛围装饰（与球体画布同例），位于无障碍树之外；面板仅以指针操作。
